# SealHack FIRE — 財務自由試算器

**線上版:https://sealhack.com**

像心理測驗一樣回答 10 張題目卡,看你最快什麼時候可以退休、是哪一型的「退休海豹」。所有計算在瀏覽器內完成,不上傳任何資料。

## 怎麼玩

1. **題目卡**:年齡、理想退休年齡、每月生活費、稅後月收入、存款與投資、貸款、大額支出、勞保勞退、投資風格、什麼時候開始定期定額。
   點選項就跳下一題;每張卡的「細項」(預計活到幾歲、加薪、貸款條件、年金金額……)可以不填,用預設值。
2. **結果**:退休人格(6 種海豹)、最快幾年幾月可以退休(樂觀 / 中性 / 悲觀)、理想退休年齡來不來得及(不到九成把握就算出每月要多存多少)、「想再快一點」的建議、報酬率滑桿、
   一生資產的三種情況(1,000 次市場模擬:樂觀、中性、悲觀三條線,撐到 95 歲的機率);
   報酬率交叉圖、需要準備多少、每年的錢怎麼分、貸款每年還多少、影響退休年齡的因素與財務體檢收在「更多分析」。

答案存在瀏覽器 localStorage,下次打開直接看結果,也可以「修改答案」。

## 投資方法(/invest/)

從測驗算出的最低報酬率出發,看歷史上持有 10 / 20 年達到它的比例;再整理六本書的方法
(馬朱利《持續買進》、柏格《約翰柏格投資常識》、巴菲特《波克夏股東信》、蒙格《窮查理的普通常識》、
馬克斯《掌握市場週期》、李錄《文明、現代化、價值投資與中國》),收斂成五個原則,逐一用台股(2003 起)、
美股(1928 起)的歷史數據檢驗。數據由 `npm run evidence` 重算(FinMind、multpl.com 公開資料)。

《持續買進》是主軸,另有分頁 /invest/keep-buying/:依你的測驗答案看現在該專心存錢還是投資,書中 17 個觀點,
以及一次投入 vs 分批、等低點、歷史高點、波動、空頭時停扣或賣出的台股 / 美股數據。

## 算什麼

退休前後用同一個報酬率 r:

- **費用與稅**:報酬率每年先扣 c(預設 0.5%),下面的 r 都是扣完的
- **勞保、勞退**:依月收入與年資估算,退休越早領得越少
- **需要準備**:以 r 撐到預計活到的年齡(預設 95 歲)所需的生活費(折回退休時)− 勞保、勞退與其他被動收入 + 退休時還清的貸款餘額
- **每年的錢怎麼分**:收入 − 生活費 − 貸款(逐年還款表)後,依序補緊急預備金、預存大額支出(支出前 3 年)、定期定額,剩下的放定存
- **存得到**:現有存款與投資(先撥預備金)+ 每年實際投入的錢,以 r 累積;退休那年定存併入
- **最低報酬率**:需要準備 = 存得到 的 r
- **最快幾年幾月可以退休**:1,000 種市場走勢中,撐到 95 歲的比例夠高的第一個年份,前後兩年內插出月份;
  分樂觀(一成)、中性(一半)、悲觀(九成)三種情況,主答案用悲觀
- **財務體檢**:貸款占收入比、緊急預備金、存款不夠的年份、資金能不能撐到 95 歲
- **一生資產**:1,000 次蒙地卡羅模擬的樂觀 / 中性 / 悲觀三條線,撐到 95 歲的機率

結果頁的金額都換成今天的錢(已扣掉通膨)。公式與假設見網站「計算方法」頁(`src/pages/method.astro`)。

## 開發

```bash
npm install
npm run dev      # http://localhost:4321
npm test         # 計算引擎測試(node:test)
npm run evidence # 重抓公開資料、重算投資方法頁的歷史數據(src/data/evidence.json)
npm run seal     # 重新產生純 CSS 的像素海豹(src/styles/seal.css)與 favicon.svg
npm run icons    # 由 favicon.svg 產生 favicon.ico、PNG 圖示與 apple-touch-icon(需要 Pillow)
npm run build    # 靜態輸出到 dist/
```

技術:Astro 5 + Tailwind CSS v4,純靜態;計算引擎 `src/lib/fire.js` 為無相依的 ES module。

> 試算結果依假設的報酬率與通膨推估,不構成投資或財務建議。
