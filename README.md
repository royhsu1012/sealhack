# SealHack FIRE — 財務自由試算器

**線上版:https://sealhack.com**

拉動報酬率,看退休要準備多少錢、存不存得到,以及最早幾年幾個月後能退休。所有計算在瀏覽器內完成,不上傳任何資料。

## 兩個版本

- **簡單版**(`/`):5 個數字(目前年齡、想幾歲退休、退休後每月生活費、目前存款與投資、每月能存下)加一個報酬率滑桿;
  通膨 2% 固定,不計貸款與年金。
- **完整版**(`/full/`):月收入與每年加薪、收入上限、多筆貸款、勞保 / 勞退與被動收入、一次性支出、緊急預備金,
  以及一生資產曲線、需要準備的拆解、每年存款、影響退休年齡的因素與財務體檢。

兩個版本共用同一份輸入(存在瀏覽器 localStorage),換版本時年齡、生活費、資產、報酬率會帶過去。

## 算什麼

退休前後用同一個報酬率 r:

- **需要準備**:以 r 撐到 95 歲所需的生活費(折回退休那年)− 勞保 / 勞退年金與被動收入 + 退休時還清的貸款餘額
- **存得到**:現有資產(扣緊急預備金)+ 每年可投入(月收入含每年加薪 − 生活費 − 貸款月付 − 一次性支出),以 r 累積
- **最低報酬率**:需要準備 = 存得到 的 r
- **最早幾年幾個月後能退休**:存得到 ≥ 需要準備 的最早年份,前後兩年內插出月份
- **財務體檢**:貸款占收入比、緊急預備金、負現金流年份、資金撐不撐得到 95 歲

公式與假設見網站「計算方法」頁(`src/pages/method.astro`)。

## 開發

```bash
npm install
npm run dev      # http://localhost:4321
npm test         # 計算引擎測試(node:test)
npm run build    # 靜態輸出到 dist/
```

技術:Astro 5 + Tailwind CSS v4,純靜態;計算引擎 `src/lib/fire.js` 為無相依的 ES module。

> 試算結果以固定報酬率與通膨推估,不構成投資或財務建議。
